# ⚡ Quick Image Compressor & Optimizer

A lightweight, 100% free, and privacy-first web utility to compress, resize, and convert images directly in your browser. 

No server uploads, zero API limits, and instantaneous results powered entirely by client-side HTML5 Canvas.

---

## 🚀 Features

- **100% Client-Side & Private:** Images never leave your device. All compression happens locally in the browser.
- **Dynamic Quality Control:** Adjust compression strength with an interactive slider.
- **Multi-Format Export:** Convert between JPG, PNG, and next-gen WebP formats.
- **Side-by-Side Live Preview:** Compare visual quality and see exact file size savings in real time.
- **Zero Cost to Host:** Pure static web code with zero backend maintenance requirements.

---

## 🛠️ Tech Stack

- **Markup & Layout:** HTML5 Semantic Structure
- **Styling:** Tailwind CSS
- **Core Processing Engine:** Native JavaScript & HTML5 Canvas API (`toBlob`)
- **Hosting:** Vercel / GitHub Pages / Netlify
